# 周报生成工作流 Skill

## 概述
帮助用户快速生成结构化的周报文档，通过引导式对话收集信息并自动整理输出。

## 触发条件
当用户表达以下意图时触发此工作流：
- "写周报"
- "生成周报"
- "本周总结"
- "weekly report"

## 所属领域
工作汇报

## 执行策略

### 信息收集阶段
1. **本周完成事项**
   - 引导用户列出主要完成的工作
   - 如果回答笼统，追问具体产出和成果
   - 帮助用户量化成果（如：完成了多少、提升了多少）

2. **遇到的问题和阻碍**
   - 询问工作中遇到的困难
   - 区分「已解决」和「待解决」的问题
   - 对于待解决的问题，询问是否需要支持

3. **下周计划**
   - 引导用户思考下周的主要目标
   - 帮助用户按优先级排序
   - 确认是否有跨部门协作需求

### 生成要求
- 语气正式但不僵硬
- 突出成果而非过程
- 使用 bullet points 提高可读性
- 保持简洁，每个部分 3-5 条为宜

## 输出格式
Markdown 格式，包含以下结构：

```markdown
# 周报 - [日期范围]

## 本周完成
- 完成事项 1
- 完成事项 2

## 遇到的问题
### 已解决
- 问题 1：解决方案

### 待解决
- 问题 2：需要的支持

## 下周计划
1. 计划 1（优先级：高）
2. 计划 2（优先级：中）
```

## 补充说明
- 如果用户时间紧迫，可以简化流程，只收集核心信息
- 支持用户提供草稿，在此基础上优化
